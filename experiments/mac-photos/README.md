# Сохранённый эксперимент Mac Photos

Этот исходник не входит в SwiftPM target и не вызывается приложением. Пользователь уточнил, что источник должен быть только iPhone, поэтому команда чтения системной медиатеки Mac и связанные разрешения отключены.

Файл оставлен для истории эксперимента. Возвращать его в активную сборку или запрашивать доступ к Mac Photos в текущем сценарии не нужно.

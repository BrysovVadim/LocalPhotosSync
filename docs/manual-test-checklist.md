# Ручная проверка на iPhone: версии 0.6.0–0.22.0

Всё в этом списке проверено в CI только сборкой, тестами и снимками экранов на тестовых данных. С реальным телефоном эти версии не запускались. Список упорядочен по риску: сначала то, что может испортить архив или занять телефон.

Подготовка: Mac с собранным приложением (`zsh scripts/build-app.sh`), подготовленный AFC runtime, iPhone на кабеле, разблокирован, доверие подтверждено. Для архивов — пустая папка на этом Mac вне iCloud Drive.

Отмечайте результат: ✅ как ожидалось, ⚠️ иначе (опишите), ⏭ не проверялось.

## 1. Перенос и архив (самое важное)

| # | Действие | Ожидаемо | Итог |
|---|---|---|---|
| 1.1 | Каталог: выбрать 3–5 фото и видео, «Проверить», затем «Сохранить выбранные…» | Папка `LocalPhotosSync-<дата>-<8 знаков>`, отчёт, сообщение об успехе зелёное | |
| 1.2 | Повторить с файлом, которого нет на телефоне (после «Проверить» — «Файл не найден») | Перенос неполный, оранжевое сообщение, есть «Выбрать несохранённые» | |
| 1.3 | Во время сохранения нажать «Остановить» | Отчёт незавершён, в «Архивах» папка с расхождениями | |
| 1.4 | Live Photo: одна неотредактированная Live Photo → «Live Photo…» | Папка `LocalPhotosSync-LivePhoto-…`, фото и MOV, проверка пройдена | |
| 1.5 | Импорт по USB: выбрать несколько файлов, «Сохранить выбранные…» | Полоса прогресса, на значке в Dock «n/N», итог зелёный | |
| 1.6 | Во время USB-импорта отсоединить кабель | Незавершённый отчёт, понятное сообщение, приложение не зависает | |
| 1.7 | Выбрать папку внутри iCloud Drive при сохранении | Предупреждение; «Выбрать другую папку» открывает выбор рядом | |
